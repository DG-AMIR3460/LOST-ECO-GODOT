# Archivos de descarga — Lost Eco

Coloca aquí el juego exportado para que el botón de descarga funcione en la web.

## Archivo requerido

- **Nombre:** `LostEco-v1.0-Windows.zip`
- **Contenido:** Carpeta exportada desde Godot con `LostEco.exe` y archivos `.pck`

## Cómo exportar desde Godot 4.6

1. Abre el proyecto en `lost-eco/`
2. Ve a **Proyecto → Exportar…**
3. Añade un preset **Windows Desktop**
4. Exporta como `LostEco.exe`
5. Comprime la carpeta de exportación en un ZIP con el nombre indicado arriba
6. Copia el ZIP a esta carpeta (`docs/downloads/`)
